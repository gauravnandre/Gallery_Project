# Gallery Project

A responsive image gallery application built with React and Tailwind CSS, using the Picsum Photos API for dynamic image data.

## Tech Stack

- React.js
- Tailwind CSS
- Axios
- Vite

## Features

- Dynamic image fetching through REST API
- Pagination with Previous/Next navigation
- Reusable Card component
- Responsive grid layout

## Installation

```bash
npm install
npm run dev
